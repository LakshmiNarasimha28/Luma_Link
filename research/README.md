# Research & Experimentation (`research`)

This directory is designated for research scripts, channel simulations, and exploratory prototyping using Python (e.g., Python 3.12).

## Scope

- Optical channel modeling and synthetic noise simulation.
- Fountain code (LT, RaptorQ) simulation and parameter tuning.
- Visual frame recovery and computer vision feasibility experiments.
- Machine learning explorations for optical symbol extraction.
