# Research Documentation (`docs/research`)

This directory contains research summaries, literature notes, and evaluation results for LumaLink algorithms.

## Key Research Areas

1. **Optical Channel Models**: Screen-to-camera optical transfer characteristics, glare, ambient light, motion blur, and frame rate synchronization.
2. **Fountain & Erasure Coding**: Comparison of Luby Transform (LT), Raptor, and Online codes for broadcast optical channels.
3. **Visual Encodings**: Comparative evaluation of 2D matrix symbologies (QR, Aztec, custom high-density colored visual frames).
